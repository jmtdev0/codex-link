# Experimental Sites adapter

`worker/index.js` implements the contract in `../RELAY_API.md` using standard Web APIs and the D1 binding `DB` declared in `.openai/hosting.json`. `npm run build` places the Worker, manifest, and Drizzle migration in the `.openai/drizzle` path recognized by Sites; `npm run validate` checks the artifact and migration journal. It requires `CODEX_LINK_ACCESS_TOKEN` as an environment secret; no keys or credentials are embedded in the code. The plugin encrypts message content before calling the Worker.

The database stores room/participant IDs and the encrypted JSON envelope, never the invitation secret or plaintext. Each envelope stops being deliverable after five minutes and is deleted when acknowledged; rooms expire after 30 minutes, and closing a room deletes its queue. Expired rows are purged opportunistically when traffic arrives, not by a cron job, so an inactive room may leave logical residue until the next request. The plugin requires HTTPS and an independent application token for the remote URL.

**Retention limitation:** D1 Time Travel may retain recoverable states for up to 7 days on Workers Free or 30 days on Workers Paid. Therefore, an ACK or TTL deletes the current row but does not guarantee that its bytes are irrecoverable from historical snapshots during that period. History contains ciphertext and metadata only; the relay does not know the E2E key. See the [Cloudflare D1 documentation](https://developers.cloudflare.com/d1/reference/time-travel/) and confirm your account's current policy.

The Site must remain private. The `.openai/hosting.json` manifest contains the ID for each deployment; `.openai/hosting.json.example` is a sanitized template for creating another Site. Non-interactive clients use the Sites service token in `CODEX_LINK_SITES_BYPASS_TOKEN`; the plugin sends it as `OAI-Sites-Authorization` only to the exact configured origin. `CODEX_LINK_ACCESS_TOKEN` is a separate application secret that must also be configured in the Site environment and on both clients. Neither value belongs in the repository.

**The complete path between two computers has not yet been validated.** The tests in `../tests/site-worker.test.mjs` run the migration and Worker against real SQLite and demonstrate that independent instances share a room and deliver ciphertext through the same database. Before sending sensitive information, test the full path from two separate computers and accounts.
